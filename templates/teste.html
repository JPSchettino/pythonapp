Os gráficos Q-Q (Quantil-Quantil) são usados para verificar a normalidade dos dados. Eles comparam os quantis de uma distribuição amostral com os quantis de uma distribuição teórica (normal). Se os pontos do gráfico estiverem próximos da linha diagonal, isso indica que os dados seguem uma distribuição normal.
